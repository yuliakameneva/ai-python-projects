# Як показати проєкти рекрутеру — покроково

1. **Розпакуй ZIP** на комп'ютері. У папці відразу повинні лежати `index.html`, `README.md`, `.gitignore`, `projects/`, `.nojekyll`.
2. **Перевір локально**: двічі клікни `index.html` — сторінка відкриється у браузері. Деякі браузери при відкритті локального HTML можуть не дозволити всі внутрішні переходи; після публікації вони працюватимуть через HTTPS.
3. На **github.com** увійди у свій акаунт → `+` → **New repository**. Назва: `ai-python-projects`, доступність **Public**. Не став галочку створення `README`, оскільки README вже у папці.
4. На сторінці нового репозиторію вибери **uploading an existing file** або **Add file → Upload files**. Перетягни **весь вміст розпакованої папки**, а не сам ZIP, у поле завантаження. У комплекті менше ніж 100 файлів, тому його можна завантажити однією операцією. Якщо браузер не бере папки, використай **GitHub Desktop**: додай розпаковану папку як локальний репозиторій, зроби `Commit` і `Publish repository` (Public).
5. Перевір на GitHub, що `index.html` лежить **на верхньому рівні репозиторію**, поруч із `README.md`. У папці `projects/` мають бути всі три проєкти.
6. У репозиторії → **Settings → Pages** → **Build and deployment** → **Source: Deploy from a branch** → **Branch: main / (root)** → **Save**. За потреби онови сторінку, щоб побачити опубліковану адресу.
7. Сайт відкриватиметься за шаблоном `https://ТВІЙ-ЛОГІН.github.io/ai-python-projects/` (адресу перевір в Settings → Pages). Переконайся, що можеш відкрити це посилання у режимі інкогніто без входу в GitHub.
8. Встав цей URL у форму **«Покажи свій проєкт»**. Альтернатива — посилання прямо на репозиторій `https://github.com/ТВІЙ-ЛОГІН/ai-python-projects`.

## Якщо хочеш коротке живе демо GraphRAG

Дотримуйся інструкцій `projects/graphrag/README.md`. У Windows потрібен Python, у WSL2 — Docker з Neo4j/Qdrant. Після підняття сервісів і відновлення баз запускається `py scripts/05_retrieval_modes.py` для показу трьох режимів; не запускай його, поки не перевіриш правильність `.env` і стан баз. Збережені CSV/PNG можна показати **навіть без запуску Docker**.

## Відеодемо (необов'язково)

Запиши 60–90 секунд через OBS/Windows Snipping Tool:
- 15 с — стартова сторінка-портфоліо;
- 25 с — результати GraphRAG і 3 режими пошуку;
- 20 с — Telegram-граф і порівняння алгоритмів;
- 15 с — приклад HTML-звіту сканера.

**Не потрібно створювати фейкову демонстрацію живого пошуку.** Якщо бази не запущені, чесно підпиши екран як збережені результати експерименту.
