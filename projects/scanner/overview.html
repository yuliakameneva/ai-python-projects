Python Web Vulnerability Scanner — DVWA Lab

Python / HTTP / HTML / security testing · навчальний прототип

Задача

Автоматизувати базовий пошук типових вебвразливостей у власному локальному навчальному середовищі DVWA. Застосунок обходить доступні статичні HTML-форми, надсилає тестові HTTP-запити, аналізує реакції сервера і генерує HTML-звіт.

Реалізація

  • utils/crawler.py — пошук HTML-форм;
  • core/http_client.py — сесійна взаємодія та локальний DVWA-login;
  • modules/ — SQLi, reflected XSS, LFI, Directory Traversal, Command Injection, HTTP-заголовки та cookie;
  • core/reporter.py — HTML-звіт із рівнями ризику та рекомендаціями.

Демонстрація

Відкрити збережений приклад звіту. Він показує 13 спрацювань (8 HIGH та 5 MEDIUM), а не 13 окремих доведених вразливостей. Звіт є прикладом запуску у DVWA; не результатом перевірки стороннього сайту.

Запуск лише у своєму DVWA

Вимоги: Python 3.10+, запущений DVWA на http://localhost та локальні стандартні навчальні credentials DVWA.

python -m pip install -r requirements.txt
python main.py

Основний entrypoint main.py розрахований на локальне DVWA; URL, логін і пароль задані для тренувального стенду. Не запускати проти чужих ресурсів або без дозволу. report.html генерується в поточній папці.

Важливі обмеження: сканер не проходить складні JS-flow, складні випадки Command Injection та LFI можуть залишатися непідтвердженими, а знайдені сигнали потребують ручної перевірки. Для публічної версії внесено мінімальну захисну зміну до core/reporter.py — HTML-екранування параметрів, payloads та рекомендацій у звіті. Інший сканувальний код збережено з архіву.
