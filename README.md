## Про використання AI

- **GraphRAG / Vector Search:** ML-ембеддинги застосовано безпосередньо у прототипі інтелектуального пошуку; він **не генерує** текстові медичні поради і не є повністю автономним агентом.
- **Telegram:** пілотний NLP-класифікатор; AI-assisted чернеткова розмітка з ручним переглядом; синтетична симуляція охоплення, не доведений вплив на людей.
- **DVWA:** класичний Python-сканер (не AI-система); демонструє навички інженерної розробки та автоматизації.

Під час роботи з AI-асистентом важливо відділяти **консультації та допомогу в написанні/аналізі коду** від самостійної постановки задачі, аналізу результатів та експериментальної перевірки.

## Статус демонстрації

Сайт працює як **статичне портфоліо**: не вимагає бекенда і показує збережені результати. **Живий GraphRAG** запускається локально через Docker + Python за інструкцією його проєкту; в цьому репозиторії немає інтернет-доступного Neo4j/Qdrant сервера.

## Публікація / конфіденційність

У репозиторій не включені `.venv`, IDE-кеші, локальні паролі, великі проміжні Telegram-файли та частина проміжних оглядових таблиць GraphRAG. Перед публікацією ще раз перегляньте код, CSV, звіти на наявність даних, які не бажаєте оприлюднювати. Не завантажуйте свій локальний `.env` або Docker volumes.
